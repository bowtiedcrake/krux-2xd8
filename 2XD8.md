# 2XD8 on this fork

This public fork of [selfcustody/krux](https://github.com/selfcustody/krux) adds one path:

**New Mnemonic → Via Entropy App 2XD8**

It draws whole BIP39 words with two distinguishable D8 dice (White / Black), matching the printed [2XD8 Entropy Booklet](https://github.com/bowtiedcrake/2xd8-entropy-booklet). It does not SHA-256 a roll string (that remains Via D6 / Via D20). The last word is the BIP39 checksum, computed by the device.

Menu, page, tests, and simulator sequences:

- `src/krux/pages/new_mnemonic/entropy_app_2xd8.py`
- `src/krux/pages/login.py` (one menu item + handler)
- `tests/pages/new_mnemonic/test_entropy_app_2xd8.py`
- `simulator/sequences/entropy-app-2xd8-demo.txt`
- `simulator/sequences/entropy-app-2xd8-demo-amigo.txt`
